# Qoder 全流程任务包（A 的活全交给它，你只做验收）

四个场景模板已经写完并全部过检（`ERROR 0 条`），所以 Qoder 不用再"创作"，它做三件事：**出 24 张图、写演示脚本、按规则扩场景**。

**每次开工前贴第 0 节那段总则**，然后按 T1 → T4 逐段贴。每段都带验收标准，不达标就让它重做，别自己动手改。

---

## 0. 总则（每轮都先贴这段）

```text
你是这个项目的执行者，我是验收人。项目：社交故事器——家长填 3 个变量，按规则生成 6 页儿童社交故事。

你必须遵守：
1. 工作目录只碰 content/ docs/ shots/，不许读写 src/，不许 git commit。
2. content/rules.json 里的数值（22 字上限、禁词表、比例）不许改，改一次就等于让所有检查假通过。
3. 任何模板类产出，交付前必须跑 `python check_social_story.py content/scenes/<file>.json`，把完整输出贴给我，ERROR 必须为 0。
4. 不确定就问我，不要自己臆断。
5. 一次只做我贴的那一段，做完停下来等下一段。
```

## T1 · 出图（24 张，最花时间的一段）

**开始前**：把 `content/image-prompts.md` 交给它，然后贴：

```text
读 content/image-prompts.md，按里面的 24 条提示词逐条生图，一条一次，不要合并批量。
每张出完立刻存成 shots/<场景id>/<页号>.webp，文件名与原提示词编号一致
（例：shots/injection/01.webp）。
每张图出来后，按文件末尾的「出图后逐张自检」4 条自查，不合格就用追加句重试那一张，最多 3 次。
3 次还不合格就停下来告诉我第几张、差在哪里，别硬凑。

全部出完后给我一份清单：场景 / 页 / 是否通过 / 重试次数。
```

**验收只看两件事**：6 张并排像不像同一个孩子；每张图里的动作和 `alt` 是不是同一件事。
**不合格重出的控制**：一次只重出一张，说清"只改哪里"，别整批重来（整批重来一致性问题会更大）。

## T2 · 扩第 5 个场景（证明"器"是真的）

```text
照 content/scenes/medication.json 的结构，新建 content/scenes/<新id>.json。
场景：<告诉我场景名和"那一刻"的画面>
读者 4-8 岁，家长念给孩子听，6 页。

硬约束：
- 第一人称"我"、现在时、不出现"你/您"；一页一句
- 模板里自己写的字 ≤18（留 4 字给变量，检查器按 slot 的 max 填满算最坏情况）
- slot 只用 who / when / where，都要有 label/default/max，max 按"常见 3 个真实输入里最长那个"估
- type 只能 descriptive/perspective/affirmative/directive，directive 最多 1 页，结尾停在肯定句
- 禁词：应该 必须 不许 不准 不能 总是 永远 乖 听话 勇敢 加油 一定要 记住
- 每页必须有 img（01.webp…06.webp）和 alt（一句话画面动作，供出图和朗读）
- 图为"动作不画身份"：成年人只给背影或侧影

交付：跑 check_social_story.py，ERROR 0，再把 JSON 全文和输出贴给我。
```

**为什么留这段**：答辩时评委问"你们只有 4 个场景？"——现场让它加一个，比你说十句话都硬。

## T3 · 演示脚本 + 答辩

```text
写 docs/demo-script.md：90 秒现场演示脚本。
0-10s 投屏只有一页绘本，孩子盯着药片，手没动（不说话，让画面说话）；
10-40s 请评委说一个场景，选场景 → 填 3 个空（谁陪/什么时候/在哪里）→ 出 6 页；
40-70s 翻两页念出来，其中一页保留"心里有点不想吃"，说明我们写的是孩子的感受不是要求；
70-90s 一句收尾，停 3 秒。
写"手上的动作"和"屏幕上发生什么"，不写功能说明；台词每句 ≤20 字；标出谁说话。
禁止说"AI 自动生成"，要说"按规则生成"，因为现场断网也能跑。
```

```text
写 docs/qa.md：5 个问题 + 30 秒回答。
「这跟给孩子看动画片有什么区别」
「谱系孩子差异那么大，6 页模板够吗」
「这些句子谁写的，有特教老师参与吗」
「孩子不肯吃药，念个故事真有用吗」
「两个人三天做的东西能上线吗」
结构：先承认边界 → 给一个具体做法 → 落回一个孩子的名字。不许喊口号，不许说"我们将持续迭代"。
```

**验收**：出声读一遍，凡是念着别扭、或者需要解释才懂的句子，全部划掉重写。


## 三条禁令（贴在 Qoder 规则里，也让 B 知道）

1. **不许改 rules.json 的数值**。把 22 改成 30，所有检查立刻变绿——这是最典型的假通过，答辩被问一句就露。
2. **不许自己加场景**到产品里。它一加就是"刷牙""写作业""分享玩具"，全是没"那一刻"的题，稀释主线。
3. **不许写 src/**。A/B 目录所有权是团队唯一的防冲突机制，破了就是两个人同时改一个文件。
