# Qoder 生图过程记录

这份是**过程证据**，不是最终素材。最终素材在 `shots/`（已裁水印、1024×730）；
这里留着 Qoder 每次出图的原始版本，用来回答评委那句"图真是 AI 出的吗、你们改了几轮"。

- `originals/` —— 2026-11-21 那轮 Qoder 会话产出的全部 62 张原始 PNG（转 webp 压缩，保留原文件名）。
  文件名规则：`<场景>_<页号>_<时间戳>_<hash>.png`。**同一个页号出现多次 = 被退回重出的版本**，
  按时间戳排序就是修改史。
- 重新导入：`python tools/import_qoder_raw.py "<Qoder 日期目录>"`（默认写到 `docs/qoder/originals`）。

## 一句话结论

Qoder 能稳定做到"按提示词出一张构图合格的水彩插画"，但**角色一致性、手势、是否出现人脸**这三件事
必须一张一张验收退回；指望一句"24 张按提示词全出完"然后收工，出来的东西不能用。

## 沉淀下来的四条硬规则（已写进 `content/image-prompts.md` 的约定里）

1. **角色设定每张都要重复一遍**，不能只在第一条 prompt 里写死。
2. **"不要清晰五官"会被执行成"没有五官的白脸"** —— 正确写法是"头部不入画"。
3. **负向手势必须明说**：模型会自作主张加"比耶"，尤其画面里有"看着某人"的动作时。
4. **顶部留白要写"自然融合"**，否则会出现笔直的接缝。

## 环境踩坑

- Qoder 的图片生成会在右下角烘焙「AI 生成」水印，prompt 里要求"不要水印"无效 → 全量产出后统一裁底部 38px
  （`tools/crop_watermark.py`）。
- 生图服务会返回 **429**，Qoder 自己会退避 60 秒重试；这时候催它没用，等或者跳过。
- 每张图大约 30–75 秒；靠轮询 `shots/<场景>/0X.webp` 的修改时间判断产出比截图判断可靠。
